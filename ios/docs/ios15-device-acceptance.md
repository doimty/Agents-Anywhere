# iOS 15 真机验收清单

本清单对应 `ios/Legacy`（bundle id `com.agentsanywhere.legacy`）产出的未签名 IPA。CI 只能证明"能编译、能打包"，不能证明"能安装、能使用"；下表把两者分开记录。

## 环境与前置

- 设备：iPhone，系统 **iOS 15.x**；如用 iPad，另记一列。
- 安装：TrollStore / AltStore / Sideloadly 安装 `AgentsAnywhereLegacy-unsigned.ipa`，或自行重签。
- 服务端：Agents Anywhere 2.1.0+（Cloud 或自托管）。
- 工作设备：Connector 在线，至少 1 台设备、1 个会话。
- 版本确认：首页底部应显示当前 `vX.Y.Z (n)`；截图时把它一起拍进去，否则无法判断装的是哪一版。

## 用例

状态取值：✅ 已通过 / ⚠️ 部分通过 / ⬜ 未验证。

| 编号 | 步骤 | 预期 | 状态 |
| --- | --- | --- | --- |
| A1 | 首次启动，输入服务器地址、邮箱、密码，登录 | 进入设备/会话列表；错误账号显示服务端错误文案 | ⬜ |
| A2 | 杀进程后重新打开 | 直接进入列表，无需再次登录（token 存 Keychain） | ⬜ |
| A3 | 退出登录，再重启 | 回到登录页，Keychain 中的 token 已删除 | ⬜ |
| B1 | 观察设备区块 | 显示设备名与「在线/离线」，与电脑一致 | ✅ 用户真机截图：`LAPTOP-MARCH` 在线 |
| B2 | 观察会话区块 | 按最近活动倒序；标题、Runtime 名、运行状态正确 | ✅ 用户真机截图：两个 DSH 会话，运行中 |
| C1 | 打开一个长会话 | 先显示最近 80 条，滚动顺畅，无空白卡顿 | ✅ 用户真机截图：时间线正常渲染 |
| C2 | 上滑到顶部，点「加载更早的消息」 | 追加更早记录，当前阅读位置不跳变 | ⬜ |
| C3 | 打开含行内代码/强调/链接的回复 | 反引号消失、链接可点；围栏代码块等宽并横向滚动 | ⬜（v0.2 起才生效，需重装后复验） |
| C4 | 观察工具调用行 | 显示真实标题、命令摘要与状态，而不是「（工具调用）」 | ⬜（v0.2 起才生效） |
| C5 | 输入一句话发送 | 气泡出现，Agent 开始回复；失败时草稿与附件被还原 | ⬜ |
| C6 | Agent 运行中点「中断」 | 运行停止，状态变为已中断/已完成 | ⬜ |
| C7 | 触发一次工具审批 | 时间线上方出现审批卡片，点动作后卡片消失、任务继续 | ⬜ |
| C8 | 触发需要输入的审批 | 弹出输入表单，提交后任务继续 | ⬜ |
| C9 | 点「照片」，选 1 张发送 | 附件胶囊出现→上传→消息带图发出；服务端可见附件 | ⬜ |
| C10 | 点「文件夹」，选 1 个文件发送 | 同上，且文件名/类型正确 | ⬜ |
| C11 | 在电脑上继续发消息，手机停留会话页 | 约 3–6 秒内手机出现新内容，无需手动刷新 | ⬜ |
| D1 | 切到后台 30 秒再回来 | 会话仍在，轮询恢复，无重复条目 | ⬜ |
| D2 | 飞行模式停留 20 秒再恢复 | 不崩溃、不刷错误横幅；恢复后轮询继续 | ⬜ |
| D3 | 深色模式 | 文字/背景对比正常，附件胶囊可读 | ⬜ |
| D4 | iPad 分屏/横屏 | 列表与时间线可用，无裁切 | ⬜ |

## 已知未覆盖（不是 bug，是本版边界）

- WebSocket 实时事件流（当前为 3 秒增量轮询）。
- 附件预览/下载、图片缩略图。
- 草稿与附件跨进程持久化、本地通知、iPad 专用布局。
- 多账号切换、公告、设置项（语言/外观/头像）。

## 证据收集

1. 录屏覆盖 A1 → C11 主路径，重点看流式回复与滚动。
2. 每张截图带上首页底部的版本号。
3. 失败时记录：用例编号、时间、设备型号/系统版本、网络状态、以及服务端同一会话的 Timeline 是否与手机一致。
